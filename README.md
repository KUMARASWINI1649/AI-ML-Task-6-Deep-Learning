# AI & ML Task 6 - Deep Learning

## Objective
Implementation of an Artificial Neural Network using TensorFlow/Keras
for Breast Cancer classification.

## Dataset
Breast Cancer Dataset from scikit-learn.

## Model Architecture
- Dense Layer: 16 neurons, ReLU
- Dense Layer: 8 neurons, ReLU
- Output Layer: 1 neuron, Sigmoid

## Training
- Optimizer: Adam
- Loss: Binary Crossentropy
- Epochs: 50
- Batch Size: 16
- Validation Split: 0.2

## Evaluation
Test accuracy obtained from the trained model.

Training and validation accuracy graph included in the notebook.
